# Registrar System Backend

Backend API for the Registrar Management System.

## Project Overview

This project provides the backend services for the Registrar System frontend.

The backend is built using Node.js, Express.js, and PostgreSQL.

## Technologies

- Node.js
- Express.js
- PostgreSQL
- JWT Authentication
- bcryptjs
- CORS
- dotenv
